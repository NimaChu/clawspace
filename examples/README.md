# Examples

Examples are intentionally curated. Inclusion here means the project can be redistributed under this repository's license; applications merely hosted by a CLAWSPACE deployment are not included automatically.

## Gravity Surfer

`gravity-surfer/` is a responsive Canvas mini-game demonstrating:

- a complete start, play, game-over, and restart loop
- touch and keyboard input
- local best-score persistence
- optional account and global score integration
- a package manifest, cover assets, and mobile-first layout
