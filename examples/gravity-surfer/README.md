# 引力波冲浪 · Gravity Surfer

> 驾驭粒子，在脉冲引力波上极速冲浪

## 玩法

- **点击 / 空格键** 让粒子从波面跳跃
- 在波峰跳起，**收集悬浮的能量晶体**获得分数
- 避开波面上的**红色尖刺**，碰到即游戏结束
- 连续收集晶体提升**连击倍率**（最高 ×8），分数翻倍
- 游戏随时间加速，波形振幅逐渐增大

## 独特玩法

**节奏物理混合**：引力波以固定节拍脉冲，尖刺和晶体随节拍生成，玩家需要感知波形节奏，在正确时机跳跃。不同于传统跑酷，这里的"地面"本身是动态的正弦波，跳跃落点需要预判波形位置。

## 技术亮点

- 纯 Canvas 2D 渲染，无任何外部依赖
- 实时正弦波形生成 + 物理重力模拟
- 粒子系统：收集爆炸、玩家轨迹、得分浮字
- 节拍驱动的游戏对象生成系统
- 响应式设计，支持触屏和键盘
- 本地最高分持久化
